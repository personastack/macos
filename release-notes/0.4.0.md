# PersonaStack 0.4.0

Release date: 2026-10-01

## Added

- Added a Concern Notifications toggle in Settings. Concern banners are enabled by default and can be turned off without disabling update notifications.

## Changed

- Concern notifications stay available when the main window is closed, including when Desktop Control has not been set up.
- Organized the menu bar into Desktop Control, Settings and Updates menus. Open PersonaStack is first, with connection status and the current retry, pause or resume action directly below it.
- Combined update information into one menu entry with download progress and the next available action.

## Fixed

- Accessibility approval now uses the current macOS permission status. Checking or approving it no longer runs a desktop action or moves the cursor.
- Accessibility approval remains separate from Screen Capture checks and desktop runtime availability.

Concern notifications currently cover the workspace selected in the app. Notifications from all owned or administered workspaces require a separate website update.
