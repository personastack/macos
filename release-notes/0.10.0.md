# PersonaStack 0.10.0

Release date: 2026-10-10

## Upgrade notes

- Existing Hermes and OpenClaw Connector users can migrate from the persona's settings in the macOS app. Review the native migration prompt before continuing. Migration pauses the persona and replaces its connection. Keep the old configuration backup until the new connection works.
- OpenClaw connections require MCP Apps. When Apps is disabled, the app asks for separate approval to enable HTML App capability and an extra local sandbox listener. Repair may restart the selected gateway. Cancel keeps the profile configuration unchanged. Apps stays enabled after disconnecting.
- Background agents require an awake, signed-in Mac. This release does not replace Linux, root-service or pre-login Connector execution.

## Added

- Connect installed Hermes and OpenClaw profiles from persona settings in the macOS app.
- Link several profiles to different personas on one Mac. Each profile connects to one persona.
- Keep linked personas available after closing app windows or quitting the app through an approved background login helper.
- Check a profile's connection, repair its setup, send a test wake or disconnect it from persona settings.

## Changed

- Wait for assigned work to finish before replacing the background helper during an app update. Canceling the update restores background admission.

## Fixed

- Open persona settings when selecting a persona's chat avatar.
