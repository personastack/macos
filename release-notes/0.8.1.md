# PersonaStack 0.8.1

Release date: 2026-10-06

## Fixed

- Check CUA Connection now opens Diagnostics with visible progress and a clear result.
- Diagnostics shows the last CUA check and a specific failure reason, with a shortcut to CUA setup.
- Desktop status checks detect unavailable CUA instead of reporting cached readiness. Completed health changes reach PersonaStack without waiting for another heartbeat.
- Recover PersonaStack's connection after standalone CUA restarts, while preserving session cleanup and paused control.
