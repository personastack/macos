# PersonaStack 0.9.0

Release date: 2026-10-06

## Added

- Open the exact concern in PersonaStack when you select its notification.

## Changed

- Make CUA setup and recovery more resilient, with clearer guidance for conflicting installations and actions that stay visible while resizing the setup window.

## Fixed

- Resume Desktop Control connection checks after wake, screen wake, session activation, or network recovery.
- Show which persona controls remote CUA cursor actions and keep its readiness status current.
- Avoid repeated Keychain access prompts when configuring additional local personas.
- Verify Codex plugins from their manifests when the CLI omits the installed version.
