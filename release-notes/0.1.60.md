# PersonaStack 0.1.60

Release date: 2026-09-30

## Fixed

- Screen Recording and Direct Capture now request access before opening macOS Settings so PersonaStack can appear in the permission list.
- Accessibility verification no longer requires Screen Recording to be enabled first.
- Microphone setup can verify recording on the current hosted app even when its voice-test helper is unavailable. Test audio is discarded.
- File and network checks keep their results when macOS returns focus after a permission prompt.
- Permission setup shows specific guidance for a required restart, a busy recorder, a missing microphone, or a failed recording test.
