# Private native control

One versioned bounded JSON request per owner-only Unix socket connection. The current-user helper is the sole connection writer. Approved environment configuration is written by native Swift. Hosted page code never chooses paths, gateway URLs, credentials or service lifecycle commands. Tests drive Dispatch and typed injected dependencies directly without listening sockets.

Each request has an eight-second context budget from socket receipt. The socket and native client allow ten seconds for the response, including reply grace. Dispatch checks expiry again after obtaining its existing owner lock. Network probes receive that finite context. Expired or cancelled work returns `operation_timeout` with fixed Check-before-retry guidance. A client cancellation does not promise rollback or stop the independently started native gateway. Update polling uses separate finite requests.

Readiness is persisted from the active session reconciler. Native status exposes finite state and assigned run IDs. It does not inspect unrelated CLI work or transcripts. Foreign connection generations and native run events cannot update an assigned run.

Repair restores selected runtime setup and unchanged owned MCP configuration. It does not renew a missing or rejected persona MCP credential. Canonical ConfigRefresh carries MCP URL/server/namespace metadata but no token material. Credential renewal requires native scoped Disconnect followed by fresh enrollment. Repair must surface that instruction instead of reporting successful credential renewal.

A repeated prepare for the same environment, workspace, persona, runtime and opaque physical profile replaces the unused earlier proof. The previous preparation cannot enroll. Another persona or environment cannot take the reservation.

Status and Check return `reconnect_required` for missing or rejected persona MCP authorization. Repair returns the same finite error before native config installation or runtime start. Runtime gateway authorization stays separate. Stored Keychain access denial returns `credential_unavailable` and asks for Keychain access before retry. It never recommends replacing a credential solely because access was denied. Keychain account names encode the complete environment, connection and secret suffix into a printable versioned account string before CoreFoundation conversion. The service namespace is fixed to this app-owned helper.

Assigned cancellation uses the current selected runtime adapter. Native stop failure leaves observation active and the command retryable. Native stop acceptance also keeps observation active until terminal readback and terminal acknowledgement. OpenClaw partial output, nonterminal wait responses and native wait timeouts keep the assigned run pending. Only explicit native terminal status can report success.

A validated API target selection persists its revision before runtime startup or native MCP installation. This records selection authority only. It does not mark readiness verified or grant startup consent. Repair rechecks the exact generation, target revision and admission state after credential verification. It updates only startup consent and native setup/ownership through the existing current-user store mutation guard. Concurrent accepted work or quiesce refuses Repair before config changes.

Quiesce rejects new assignments while preserving the selected adapter for accepted work. Accepted RunStart redelivery replays its acknowledgement before new-run admission checks. A reconnected quiesced helper may reconstruct the selected adapter to observe or stop that accepted assignment. It does not start the runtime or install config during that reconstruction.

Private status/check/repair connection rows carry `connection_generation` and optional `prepared_target` with the persisted workspace/account/profile/runtime identity. Swift uses it only after authenticated exact binding readback to finish interrupted target selection through normal enrollment completion. These fields never reach the WebView's sanitized connection rows.

Hermes Repair has a private `hermes_host_confirmed` flag. Generic profile repair consent is insufficient to change host API configuration or grant shared gateway startup. A stopped default host reports `hermes_host_consent_required`. Running unproven/ineligible hosts return the fixed native manual-setup diagnostic. Named-profile key and MCP repair can attach to an eligible verified running host without host consent. Enrollment explicitly clear startup authority. Generation and target-revision receipt checks apply before either mutation. Hermes readiness checks selected-profile API/configuration and direct PersonaStack core tools. It does not claim loaded native MCP discovery. Actual native tool invocation remains installed release acceptance.


Standalone migration operations and enrollment capture fields are rejected as unknown input. The helper never reads Connector state or its Keychain namespace and never controls its services. Prepare and enroll reserve only native app-owned profile scope. App-owned Review profile cleanup remains fenced by exact retained identity and authenticated revocation readback.
