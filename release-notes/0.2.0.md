# PersonaStack 0.2.0

Release date: 2026-09-30

## Changed

- Simplified Desktop Control setup to Accessibility, Screen Capture, Full Disk Access and Microphone. Local Network appears only when needed for the selected services.
- Combined Screen Recording and Direct Capture into one Screen Capture step. Full Disk Access replaces separate folder and volume approval steps.
- Automatically set up notifications, launch at login, updates and sleep prevention when you open the setup window. Confirmed settings show a check. macOS may still ask for approval.

## Fixed

- Notifications and launch at login no longer block Desktop Control setup when approval is pending or unavailable.

Full Disk Access still needs manual approval in System Settings. Its broad access remains unverified. Desktop Control remains unavailable while this Mac is locked.
