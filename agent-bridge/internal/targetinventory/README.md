# targetinventory

Private app-owned targetinventory support for the selected native profile. API and gateway retain product/auth/protocol authority.

OpenClaw agent candidates remain private helper/native UI inventory. They are HMAC identities over the selected physical profile, config snapshot and declared agent ID. They never change the API profile identity. Resolve requires the persisted explicit dispatch agent to remain present in that profile. Discovery supports configured `agents.entries` and `agents.list`, refuses conflicting shapes and exposes the upstream implicit `main` only when neither roster property exists. Explicit empty or malformed rosters refuse selection. Strict JSON is the current supported config format; unsupported configs carry `native_config_unsupported`.
