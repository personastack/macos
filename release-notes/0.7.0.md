# PersonaStack 0.7.0

Release date: 2026-10-04

## Upgrade notes

- Run Desktop Control setup again to verify the expanded permission checks. Full remote setup requires macOS 15 or later. Ordinary chat remains available on macOS 14.
- Local persona execution now uses connections to installed Codex and Claude harnesses. Configure a harness connection for each persona and workspace you want to use.
- Install PersonaStack through the included package for the signed locked-control component. Locked-session operation still requires qualification on your Mac.

## Added

- Added a guided Desktop Control setup flow for Accessibility, screen capture, protected files, browsers, clipboard and local-network access.
- Added the pinned CUA tool catalog with owned sessions, local recording and bounded trajectory replay. Browser operations remain subject to local approval and CUA's supported security mode.
- Added official CUA perception installation to setup on supported Apple Silicon Macs. Setup shows the download and asks for installation approval. Intel Macs do not have a supported perception package.
- Added Codex and Claude harness connections with profile selection and activity reporting for each persona connection.
- Added workspace skill upload and download through a selected local folder.
- Added native pinned graph windows with clearer controls on light backgrounds.

## Changed

- Microphone approval now happens when you choose audio input in chat. Desktop Control setup no longer requests it.
- Permission setup advances after verified approvals and offers targeted recovery when a check fails.

## Fixed

- Permission restart preserves setup navigation and allows a fresh setup attempt after relaunch.
- Chat windows close without ending the conversation or waiting for chat availability.
- Replacing a skill selected directly in a folder updates that skill in place.
- Harness activity reporting covers every connection attached to the selected profile.
