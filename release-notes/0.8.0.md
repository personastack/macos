# PersonaStack 0.8.0

Release date: 2026-10-06

## Upgrade notes

- Desktop Control now uses standalone CUA. Open the PersonaStack menu, choose Desktop Control → Set Up CUA, then install CUA or reuse your existing compatible installation.
- Complete CUA's permission setup when prompted. Permissions previously granted to PersonaStack do not transfer to CUA.
- PersonaStack's remote file and shell tools and locked-screen helper are no longer available. Desktop Control uses CUA's supported actions and local settings.

## Added

- Install and start standalone CUA from PersonaStack's setup window.
- Check CUA's connection separately from the PersonaStack cloud connection.

## Changed

- CUA owns its permissions and login service. It stays installed when PersonaStack is removed.
- Pause, Stop, and Disconnect affect PersonaStack's access without stopping CUA for other clients. PersonaStack must remain running for its cloud agents to connect.
- Replaced PersonaStack's desktop permission checklist with CUA setup.

## Removed

- Removed PersonaStack's embedded CUA service and native remote file and shell execution.
- Removed the locked-screen helper from new installations. Upgrades restore its saved system policy before removing the old component. A conflicting policy stops the upgrade for review.

## Fixed

- Keep desktop sign-in sessions refreshed while the app is open and after wake.
- Keep Stack Stream and persona activity window titles clear of the window buttons when opening or resizing them.
