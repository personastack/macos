# PersonaStack 0.1.59

Release date: 2026-09-30

## Fixed

- Fixed the app's signing identity so macOS can identify PersonaStack consistently across updates.
- Added recovery instructions when Settings shows an enabled permission that macOS is not granting to the current app.

## Changed

- This release uses a persistent self-signed certificate. It is not Developer ID signed or notarized.
- Reapprove permissions once after updating from an unsigned build. For Accessibility, remove the old PersonaStack entry and add PersonaStack.app from Applications. For Screen Recording and Microphone, turn PersonaStack off and on in Settings. Relaunch if macOS requests it, then retry the Setup buttons.
