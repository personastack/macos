# PersonaStack 0.5.0

Release date: 2026-10-02

## Upgrade notes

- This release moves from the previous self-signed identity to PersonaStack, LLC's Apple Developer ID. macOS may require permission approval again. For Accessibility, remove the old PersonaStack entry and add PersonaStack.app from Applications. For Screen Recording and Microphone, turn PersonaStack off and on. Relaunch if macOS requests it.

## Changed

- The app and installer are signed with PersonaStack, LLC's Apple Developer ID and notarized by Apple.
- Desktop Control attempts an authorized operation without waiting for macOS to confirm the screen is unlocked. The operation reports its actual result.
- Chat and activity popout windows use consistent titlebar sizing.

## Fixed

- Removed repeated Keychain prompts when Desktop Control reads its saved machine credential.
- Improved recovery guidance when macOS still holds an older Accessibility approval.
- Check Screen Capture approval independently from Accessibility approval.
- Reject incomplete Desktop Control setup instead of reporting the machine ready.
- Improved Desktop Control command cancellation and connection recovery.
- Permission setup refreshes macOS approval and explains when PersonaStack must restart.
