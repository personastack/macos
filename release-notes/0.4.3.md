# PersonaStack 0.4.3

Release date: 2026-10-01

## Fixed

- Accessibility setup can confirm access with read-only application metadata and input-permission checks when macOS's process trust flag reports no access. The check never clicks, types or reads window contents.
- Desktop Control and its permissions checklist use the same Accessibility check.
- Screen Capture shows Ready when macOS grants it. Its status no longer depends on Accessibility or a running desktop-control service. Permission checks do not take screenshots.
- Removed obsolete Keychain recovery messages saved by earlier versions.

## Upgrade notes

- If Accessibility is enabled in Settings but still reports Not granted after updating from an unsigned build, remove the old PersonaStack entry. Add PersonaStack.app from Applications and enable it again. This replaces approval tied to the old binary.
