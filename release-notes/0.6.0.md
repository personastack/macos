# PersonaStack 0.6.0

Release date: 2026-10-04

## Added

- Added Direct Capture, Safari Automation, Safari JavaScript and Clipboard checks to Desktop Control permission setup. macOS and Safari still require your approval where applicable.
- Added a Refresh button beside the main window's Back and Forward controls.

## Changed

- Command-Q now hides PersonaStack's windows and keeps the menu bar, local runs and remote control running. Choose Quit PersonaStack from the menu bar icon to exit fully.

## Fixed

- Chat windows close immediately with the close button or Command-W, even when chat is unavailable.
- Fixed Quit and permission restart getting stuck while native cleanup waits to run. Failed local cleanup stays visible and can be retried.
- Permission setup rechecks newly approved notifications and microphone access. Restart-required rows use a yellow indicator.
- Full Disk Access setup preserves existing approval and gives clearer instructions for adding the running app. Returning from Settings rechecks access.
- Desktop Control gives specific recovery steps after failed or uncertain actions.
