# PersonaStack 0.2.7

Release date: 2026-10-01

## Fixed

- Opening Desktop Control setup automatically verifies current Accessibility, Screen Capture, Full Disk Access, Microphone and applicable Local Network access. Reopening setup runs fresh checks after an app restart or page change.
- Permissions that need approval retain their Setup actions. Automatic checks preserve active recordings and remote tasks. Optional checks do not delay Finish after Accessibility is verified.
- Microphone checks discard their short test recording. Protected-folder checks discard directory entries without reading file contents. Closing setup or choosing Finish cancels pending checks.
