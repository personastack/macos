# PersonaStack 0.2.6

Release date: 2026-09-30

## Fixed

- Reopening Desktop Control setup preserves valid Microphone verification without recording another audio test.
- Previously verified Full Disk Access and Local Network checks refresh when setup reopens or regains focus. Failed checks keep their recovery instructions and wait for an explicit retry.
- Closing setup or choosing Finish cancels pending checks and prevents old results from replacing newer permission status.
