# PersonaStack 0.11.0

Release date: 2026-10-11

## Upgrade notes

- Desktop Control now includes CLI commands on the selected Mac. Commands use the signed-in account's files, installed tools, and macOS permissions. Review which personas have access to that computer. Keep the Mac awake and the PersonaStack app running.
- Concern notifications can show a persona's picture, name, and a shortened concern preview. Review notification preview visibility in macOS System Settings if the screen is shared.

## Added

- Run CLI commands through Desktop Control and receive their output and exit status.
- Use interactive terminal sessions for programs that need a terminal. Read partial output, send input, check status, or cancel the session.
- Show the persona's picture and name with a shortened concern preview in macOS notifications. Clicking the notification opens its concern in the main app.

## Fixed

- Refresh Desktop Control availability after waking or unlocking the Mac.
- Recover stalled cloud connections after wake, unlock, or a network change without repeating an action.
- Finish pending Desktop Control cleanup after a temporary failure before admitting new work.
- Stop managed CLI jobs when their session is canceled or Desktop Control access is paused or revoked.
- Keep CLI output pages and previews bounded, including when output closes before the command exits.
- Preserve joined emoji in concern previews.
