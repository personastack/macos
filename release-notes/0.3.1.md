# PersonaStack 0.3.1

Release date: 2026-10-01

## Fixed

- Opening Desktop Control and checking setup status no longer trigger Keychain password prompts.
- Retry Remote Control in the menu bar can restore access to an existing Desktop Control credential without replacing the installation.
- Older saved credentials use the most recent matching server entry during migration.

If Desktop Control needs Keychain access, choose **Retry Remote Control** from the PersonaStack menu. If macOS asks for authorization, choose **Always Allow** to remember this app. Older credentials can require this once after updating.
