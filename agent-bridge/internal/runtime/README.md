# runtime

Native adapters implement authenticated full-control Hermes runs and OpenClaw operator gateway paths. Detection requires progress and stop support. Only assigned run events feed observation. No legacy response, CLI dispatch or transcript-observer fallback can become Ready.

OpenClaw static tools.catalog describes capabilities only. Native readiness uses an explicitly consented MCP Apps setup session. Empty sessions.create and mcp.app.discover warm the selected session without a model run. sessions.describe brackets tools.effective with exact agent/key/ID and optional lifecycle revision checks. Normal Check reads only the retained setup session. Assigned dispatch verifies its exact conversation/namespace session before agent submission and includes the native existing-session fence. Denied, foreign, cold, reset or auth failures submit no agent run. See [runtime support](../../RUNTIME_SUPPORT.md#openclaw-mcp-apps-and-no-model-readiness).

Hermes receives the API's composed prompt unchanged. The canonical API conversation ID and issued MCP namespace determine a bounded `X-Hermes-Session-Key`. The selected profile's native owner resolves that declared conversation across transcript compression. The request omits `session_id` so it cannot override the declared conversation. An assignment without a conversation retains the existing per-run `session_id` fallback. `Idempotency-Key` is the API assignment ID. Native continuation state never becomes PersonaStack's durable conversation or prompt authority.

Hermes uses the same default-host listener for selected profiles. Every native HTTP path is scoped under `/p/<profile>/`. Named API authentication never falls back to the host key. The pinned Hermes API has full run control but no supported live gateway MCP catalog. Configured names and CLI tool summaries are not loaded-registry evidence. Hermes readiness requires selected-profile configuration, authenticated full-control API and direct PersonaStack MCP verification. It permits assigned wake testing. It does not claim native MCP discovery. Installed release acceptance must prove an actual native PersonaStack tool invocation during an assigned wake.

The unsupported Hermes native-catalog diagnostic helper is not part of configured readiness. It still refuses to fabricate a loaded catalog.
