# PersonaStack 0.1.57

## Improvements

- Run personas in a dedicated local chat window using Apple containers. Local Run requires Apple silicon, macOS 26 or later, and the Apple container runtime.
- Check access to mounted external and network volumes from the permission checklist. Choose a volume to verify access.
- Check protected folder access from the permission checklist with guidance for opening macOS privacy settings.

## Fixes

- Verify microphone access through the same recorder used for voice attachments.
- Preserve completed permission-check results while the checklist refreshes.
- Show readable release notes inside the update window instead of only a GitHub comparison link.
