# PersonaStack 0.4.2

Release date: 2026-10-01

## Upgrade notes

Existing Desktop Control credentials migrate automatically when macOS allows a silent read. If the old credential is blocked, sign in and use Add this desktop to set up a new connection. You can remove the old integration through its normal management controls.

## Changed

- Desktop Control stores its machine credential in a private file for each server profile. Startup, setup, status checks and menu retries no longer request Keychain authorization.

## Fixed

- Refresh Status no longer repeatedly fails when an old Keychain credential requires authorization.
- Successful credential retries clear saved Keychain error messages without clearing unrelated connection errors.
