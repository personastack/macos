# Private native control

One versioned bounded JSON request per owner-only Unix socket connection. The current-user helper is the sole connection writer. Approved environment configuration is written by native Swift. Hosted page code never chooses paths, gateway URLs, credentials or service lifecycle commands. Tests drive Dispatch and typed injected dependencies directly without listening sockets.

Native `migration_prepare` carries the normal environment/workspace/persona/runtime/profile/document scope plus exact legacy connection ID and generation. Result is an opaque migration ID and `user_launch_agent` service scope. Native Swift retains that migration ID. Only `enroll` accepts it. Helper reads the two known current-user Connector state locations and the old Connector Keychain namespace. It does not import old bridge keys. Missing credentials, multiple old matches, busy runs and mismatched hosted identity fail before config mutation. The captured config remains unchanged until the new API-selected target configures new native MCP credentials. A changed old entry, changed symlink or replacement-key collision returns cleanup_required. The exact original native config backup stays in the owner-private migration directory. A system Connector requires explicit administrator migration outside this user helper.

Readiness is persisted from the active session reconciler. Native status exposes finite state and assigned run IDs. It does not inspect unrelated CLI work or transcripts. Foreign connection generations and native run events cannot update an assigned run.

`migration_repair` lets native Resume Migration rebind one unconsumed in-memory capture to a new document after authenticated persona/workspace absence readback. Environment, persona, workspace, runtime and opaque profile must match the original capture. Missing, expired, ambiguous or foreign captures refuse repair. It does not read new paths, regenerate credentials or mutate native config. This handles GUI navigation while the login helper remains running. Restart recovery remains an installed-app acceptance case.

Status always returns `pending_migration_count`. It includes unexpired unconsumed captures and enrolled bindings whose captured entry is not yet replaced. Updating or stopping the helper while this count is nonzero returns busy. `migration_cancel` discards only an unconsumed exact document capture after native authenticated readback proves the original scoped connection and generation still exists. It leaves the original config backup and runtime config intact. Expired or helper-restart captures cannot be recreated by `migration_repair`. That boundary requires an explicit user recovery of the verified old native entry and pause state before reconnecting.

Repair restores selected runtime setup and unchanged owned MCP configuration. It does not renew a missing or rejected persona MCP credential. Canonical ConfigRefresh carries MCP URL/server/namespace metadata but no token material. Credential renewal requires native scoped Disconnect followed by fresh enrollment. Repair must surface that instruction instead of reporting successful credential renewal.

`migration_help` accepts the normal native scope and the same authenticated persona/workspace absence readback. It returns `profile_label`, `profile_config_path`, `legacy_entry_key` and `backup_directory` to the native client only. Swift must never forward those fields to WebView code. The helper checks known private legacy metadata and the exact selected native entry endpoint or legacy invocation. This is manual inspection guidance. It does not establish credential custody or authorize automatic deletion. No Keychain credential is read. Missing, ambiguous or foreign metadata refuses guidance. Native keeps the persona paused while it shows the exact old entry and backup location. After explicit manual removal of that old entry, ordinary prepare can resume. Prepare refuses fresh enrollment over an uncaptured known legacy entry.

A repeated prepare for the same environment, workspace, persona, runtime and opaque physical profile replaces the unused earlier proof. The previous preparation cannot enroll. Another persona or environment cannot take the reservation.

Status and Check return `reconnect_required` for missing or rejected persona MCP authorization. Repair returns the same finite error before native config installation or runtime start. Runtime gateway authorization stays separate. Stored Keychain access denial returns `credential_unavailable` and asks for Keychain access before retry. It never recommends replacing a credential solely because access was denied. Keychain account names encode the complete environment, connection and secret suffix into a printable versioned account string before CoreFoundation conversion. Old Connector migration lookups retain their established namespace and reject NUL account input.

Assigned cancellation uses the current selected runtime adapter. Native stop failure leaves observation active and the command retryable. Native stop acceptance also keeps observation active until terminal readback and terminal acknowledgement. OpenClaw partial output, nonterminal wait responses and native wait timeouts keep the assigned run pending. Only explicit native terminal status can report success.

A validated API target selection persists its revision before runtime startup or native MCP installation. This records selection authority only. It does not mark readiness verified or grant startup consent. Repair rechecks the exact generation, target revision and admission state after credential verification. It updates only startup consent and native setup/ownership through the existing current-user store mutation guard. Concurrent accepted work or quiesce refuses Repair before config changes.

Quiesce rejects new assignments while preserving the selected adapter for accepted work. Accepted RunStart redelivery replays its acknowledgement before new-run admission checks. A reconnected quiesced helper may reconstruct the selected adapter to observe or stop that accepted assignment. It does not start the runtime or install config during that reconstruction.
